## Deskripsi Tugas
Repository ini berisi hasil pengerjaan Praktikum 2 (HTML Lanjutan) yang mencakup penerapan:
1. Tabel HTML (`<thead>`, `<tbody>`, `<tfoot>`, `colspan`)
2. Form Input & Validasi HTML (`required`, `minlength`, `type`)
3. Elements Semantic HTML (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`)
4. Elemen Multimedia (`<audio>` dan `<video>`)
5. Proyek Mini Biodata Mahasiswa

## Langkah-Langkah Pengerjaan
1. Membuat struktur folder `Lab2Web`.
2. Menyusun file `index.html` dan `biodata.html`.
3. Menambahkan media berupa audio (`audio.mp3`) dan video (`video.mp4`) di folder `media/`.
4. Menguji seluruh elemen dan validasi form di browser.
5. Melakukan screenshot hasil tampilan browser.
